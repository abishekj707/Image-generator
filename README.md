# AI Image Generator 🚀

An AI-powered web application that generates images from text prompts using OpenAI API.

## 🔧 Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- OpenAI API

## ✨ Features
- Generate images from user prompts
- Real-time API integration
- Clean and responsive UI
- Fast and optimized performance
